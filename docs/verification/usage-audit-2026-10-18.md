# 统计、更新与 Pi 原生测试修复 — 2026-10-18

## 根因和修复

- **DSH**：原生 `turn:step` 仅在单个会话内唯一，报表却按 `(tool, event_id)` 全局去重，导致不同会话的调用被丢弃。适配器现在加入原生会话 ID，同一会话副本仍去重；模型归属优先取每次响应的模型。截图原生总量 85,334,431 可由对应日志前 243 条 usage 精确重算；截图与后续扫描存在活跃写入时间差，不把不同时间快照当作同一状态。
- **Devin**：`step-N` 存在同样碰撞，现加入会话 ID。此外 ATIF 会省略值为零的 `cached_tokens`，原先因此丢弃整次调用；现在仅将缺失字段视为零，非法字段仍标记不完整。本机 14 份 transcript 的 `final_metrics` 支持该语义。
- **CodeBuddy / Command Code / MiniMax Code**：无原生消息 ID 时的行号回退加入来源或会话作用域，避免不同文件之间误去重。正常原生 ID 保持原有语义。
- **OpenCode**：迁移到 `session_v2` 的记录仍保留创建时的 1.x 版本号，原先只接受 2.x，导致本机 430 个会话全部解析失败。现在按已支持的存储结构读取兼容的 1.x / 2.x 会话；新旧索引合并去重后检查来源上限；用量读取取消 4,000 行截断，展示消息仍遵循共享上限。迁移遗漏的旧消息按 ID 补读，已迁移消息不会重复累计。新旧会话更新时间共同参与缓存指纹。
- **Devin 更新**：Windows 旧入口 `https://static.devin.ai/cli/install.ps1` 返回 403，改为 `https://cli.devin.ai/install.ps1`。新脚本 GET 200；其 manifest 和 Windows ZIP 地址也返回 200，manifest 含 SHA256。未执行安装器，不将网络入口验证称为完成实际安装。
- **中文日志**：共享进程执行器设置 PowerShell UTF-8 输出，并分别缓存 stdout / stderr 的不完整 UTF-8 字节，避免分块边界产生乱码。已运行真实 Windows PowerShell 中文异常回归。
- **Pi 原生插件测试**：移除精确发布版本白名单，校验包身份并运行实际发现、禁用替换与安装路径断言。本机 `@earendil-works/pi-coding-agent` **1.3.0** 已通过。生产适配器原有兼容范围不变。

CLI 特有的路径、字段、ID、迁移兼容和安装命令均留在各自 `src-tauri/src/adapters/<cli>/` 内。共享历史服务仅明确事件 ID 契约并优化通用检索和聚合；共享维护服务仅修复编码。没有新增按 CLI ID 分派的服务逻辑，也没有改动 IPC 或数据库 schema。

受影响适配器已升级解析指纹。运行新构建后，下次刷新会重建这些来源的索引，无需删除本机数据库。

## 性能

使用现有 `history::performance_refresh_readonly_local`，Windows test profile、本机原始来源、临时索引。优化采用 `memchr` 字节检索、借用 SQLite 行字符串，并复用连续相同模型的索引，减少全量扫描和报表聚合的分配。

| 操作 | 修改前 | 修复及优化后（首次测量） | 最终补读修复后复测 |
| --- | ---: | ---: | ---: |
| 冷扫描建索引 | 34,431 ms | 25,882 ms | 29,463 ms |
| 无变化扫描，两次 | 743 / 617 ms | 374 / 373 ms | 559 / 304 ms |
| 全量统计，三次 | 1,384 / 1,634 / 1,420 ms | 1,239 / 1,339 / 1,245 ms | 1,407 / 1,545 / 1,239 ms |
| 扫描失败来源 | 430 | 0 | 0 |
| 报表用量记录 | 约 195,962 | 约 220,437 | 约 220,587 |

首次后测在补回 OpenCode 单条未迁移消息之前完成。最终复测扫描 2,669 个来源、报表含 2,335 个会话；活跃日志仍持续增加记录，因此两次“无变化”扫描也可能有少量增量。记录量增长主要来自纠正漏算，时间还受磁盘缓存、活跃写入和测试构建影响；这是本机测量，不是发布版性能保证。报表耗时有波动，不单独承诺固定比例提升。
