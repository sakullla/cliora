# 需求：五页界面体验优化

日期：2026-09-30

## 一屏摘要

- 目标：让五个现有页面更易扫读和操作，主任务与关键状态先被看到（R1）。
- 使用者：在本机日常切换、启动和整理 CLI 的人（R1）。
- 范围：主窗口壳层及快速开始、工具与连接、资料库、使用记录、设置（R1）。
- 关键行为：可重排分组和主按钮；主次样式一致；常用步数不增加，确认边界不变（R1、R2、R3）。
- 成功标准：浅色与深色、三种宽度下，主操作在当前视图前部且可聚焦；失败说明下一步（R1、R2、R3）。
- 不做事项：不新增能力，不改写入与同步规则，不重做托盘，不换主题和图标体系（R4）。

## 完整需求

### R1 各页先呈现主任务与关键状态

行为：主窗口仍由快速开始、工具与连接、资料库、使用记录、设置五个页面组成。允许重排每页的信息分组和主操作位置，使当前视图的主任务，以及会影响下一步判断的状态，出现在该视图的前部。诊断、高级选项和破坏性操作靠后，或保持为视觉上次级。

各视图的主任务为：

- 快速开始：查看已管理工具的状态，并从已有项目启动或进入对应工具。
- 工具与连接：在原生配置、MCP、Skills 三个既有视图中，分别完成保存当前文件、保存或保存并使用命名配置、保存并应用 MCP、导入或安装 Skill。
- 资料库：在提示词与长期规则之间查找条目，并复制全文或编辑保存。
- 使用记录：在会话与用量之间查找本机记录；会话侧优先搜索、按工具筛选和收藏，再查看详情或在外部终端继续。
- 设置：常规中管理 CLI、主题、外部终端和图标；迁移与同步先看总览，再进入一项导出、导入或 WebDAV。

适用与失败边界：主导航、工具切换、原生配置/MCP/Skills 切换、资料库种类切换、会话/用量切换和设置标签留在内容组之前。当前文件与命名配置、上述切换和两个设置标签仍然分开。冲突比较、未保存修改、未应用、目录不可用、扫描不完整和恢复失败，显示在受影响动作的同一视图中，不折进无关分组。视图因安装、目录或恢复失败而无法继续时，失败说明和重试占据该视图前部。无数据时，前部是空状态和已有的恢复动作，例如前往设置或关联项目。优化前在当前视图中直接可见的完成动作和页面内切换，优化后仍直接可见；本来就在披露中的高级项可以继续留在披露中。

验收：

- 浅色与深色下，窗口宽 1360 与 900 时，已有项目的快速开始不滚动就能看到工具状态和至少一个项目的「启动」。
- 窗口宽 640 时，项目的「启动」仍在「项目选项」之前，且不需要先打开其他页面。
- 命名配置视图中，「保存并使用」位于该视图前部；「删除」不是该视图的强调动作。
- 使用记录的搜索、工具筛选和收藏出现在导出与项目关联之前；可恢复的会话在详情旁提供「在外部终端继续」。
- 迁移与同步先显示总览；导出、导入和 WebDAV 连接编辑一次只展开一项。
- 存在未保存修改、应用冲突或目录不可用时，该状态与对应处理动作出现在同一视图。

### R2 常用步数与确认边界保持不变

行为：重排不增加已有常用任务的操作步数，也不改变哪些动作需要确认。工具、项目和方案已配置时，从快速开始切换一个已保存配置，或启动一个 CLI，仍各在 1–3 次点击内完成。其他页面上，进入该页后完成当前视图已有的保存、复制、收藏、筛选、主题变更，或开始一次导出/导入预览，不比优化前多一次跨页跳转，也不多一次普通确认。

适用与失败边界：普通保存、页面切换和主题变更不新增确认。覆盖冲突、删除、丢弃未保存修改、可能计费的诊断，以及需要系统授权的动作，仍各只确认一次；取消获得初始焦点，Escape 取消且不应用。已有的丢弃草稿确认不得再叠加第二次。切换页面后，资料库和工具页已有草稿、当前选择与未保存标记仍然保留。浏览器预览中，重排后的保存和设置控件仍表明原生配置与凭据不可用，不能呈现为已经写入本机。YOLO 仅在该 CLI 已有确认的原生参数时作为次级动作出现，不成为默认启动。

验收：

- 已配置时，快速开始完成一次已保存配置切换或一次普通启动，点击次数为 1–3，且中途没有确认框。
- 保存当前原生文件、保存资料库正文、更改主题时，不出现确认框。
- 删除资料、丢弃未保存修改或发送可能计费的最小请求时，只出现一个确认；初始焦点在取消上，Escape 后原内容保持不变。
- 资料库或命名配置有未保存修改时离开页面再返回，修改仍在。
- 浏览器预览中，设置与工具页的保存路径明确不可写入本机原生配置。

### R3 共享的视觉层级与状态反馈

行为：继续使用已确认的鼠尾草绿浅色与深色，以及现有五个主导航。通过统一的文字层级、间距、对齐和主次按钮样式改善观感。五个页面共用同一套强调主操作、非强调次操作、空状态、错误提示和进行中状态。错误说明失败项和下一步，使用使用者能够执行的说法。扫描、同步、获取模型和安装检测的进行状态出现在发起该操作的位置；进行期间仍可切换到不依赖该结果的其他页面。

适用与失败边界：视觉加强不得隐藏 R1 的关键状态，不得降低正文可读性，也不得用遮挡内容或推迟状态出现的装饰动效代替反馈。主操作可以用键盘聚焦，焦点可见。窗口宽 1360、900 和 640 时，主导航标签和当前视图前部主操作的文字保持可识别。本次不新增大字号、高对比或密度开关。

验收：

- 浅色与深色下，五个页面的主操作使用同一种强调样式，次操作使用同一种非强调样式，二者可以区分。
- 任一页面的失败提示同时包含失败项和可执行的下一步。
- 使用记录正在后台扫描，或工具页正在获取模型时，进行状态可见，并且可以打开另一个页面。
- 键盘可以将焦点移到当前视图前部的主操作，焦点位置可见。
- 在上述三种宽度和两种主题下，五个导航名称和前部主操作不被截断到无法辨认，也不被其他元素挡住。

## 不做事项

### R4 不扩大能力、规则或品牌范围

行为：本次不新增跨页搜索、命令面板、可配置快捷键、密度开关或新页面。不改变启动、配置写入、凭据保存、同步、导入和导出的既有结果。不重做托盘菜单。不更换鼠尾草绿主题，不更换工具图标体系；设置中已有的自定义图标与恢复默认仍然可用。

适用与失败边界：若某种重排必须依靠新入口才能减少点击，则保持原有步数，不为此新增入口。托盘仍完成既有的配置切换、项目启动、显示主窗口和完全退出。页面优化不改写 CLI 是否接受某项配置的判断，也不把估算费用显示为账单。

验收：

- 五个页面中不出现跨页搜索、命令面板、快捷键设置或密度切换。
- 主导航仍只有原来的五个目的地；主题选项仍只有跟随系统、浅色和深色。
- 托盘完成一次已保存配置切换的点击次数和入口保持优化前的结果。
- 保存、应用、启动、导入和同步的成功或失败结果与优化前相同，页面只改变这些结果的呈现位置和主次。
